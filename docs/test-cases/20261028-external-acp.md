# 외부 ACP 등록 실제 시험

- 근거: 사용자가 승인한 별도 개발 빌드의 범용 ACP 등록. 공식 앱·기존 대화 보존, 맥미니 Hermes 내부 Jev 유지.
- 입구: ORCA_EXTERNAL_ACP_CONFIG 등록 파일 → 개발 앱의 agentSession.agents 및 일반 채팅.
- 시험 데이터: E2E_EXTERNAL_ACP_20261028, 개발 전용 사용자 데이터 경로. 실제 Hermes·Chrome은 가짜로 대체하지 않는다.

| ID  | 준비와 입력                                                  | 기대 결과                                                                 |
| --- | ------------------------------------------------------------ | ------------------------------------------------------------------------- |
| C1  | 고유 ID·절대 실행 파일·인자 배열을 등록하고 앱 시작          | 기존 에이전트와 외부 ACP가 함께 조회되고 shell 없이 해당 실행 파일만 시작 |
| C2  | 내장 ACP ID 충돌·중복 ID·잘못된 경로·알 수 없는 필드         | 등록 거절, 프로세스 미실행, 비밀 값을 오류에 출력하지 않음                |
| C3  | 등록 파일이 없거나 다른 사용자/쓰기 권한 노출 파일           | 외부 코드 실행 안 함, 기존 에이전트 기능 유지                             |
| C4  | Lohtu 일반 채팅에서 고유 시험 문구 요청                      | 맥미니 기존 Hermes 응답이 한 번 표시, 내부 Jev 모델 선택 유지             |
| C5  | 같은 채팅에서 README 읽기 위임 및 시험용 Chrome 탭 제목 요청 | 실제 실행기 영수증·보고 모델, 맥북2 소유 시험 탭 제목 확인                |
| C6  | 완료된 대화를 닫고 개발 앱 재시작 후 후속 요청               | 같은 원격 ACP 세션 재개, 과거 본문 보존, 중복 전송 없음                   |
| C7  | 실행 중 취소                                                 | 현재 세션만 취소, 완료·실패를 취소로 덮어쓰지 않음                        |
| C8  | 공식 앱 및 기존 대화 조회                                    | 공식 앱 서명·원래 사용자 데이터 보존, 개발 앱 별도 경로 사용              |
| C9  | 임의 외부 ID를 등록하고 일반 채팅 목록 조회                  | 내장 TUI 이름과 관계없이 새 ID가 일반 채팅으로 선택 가능                  |
