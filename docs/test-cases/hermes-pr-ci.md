# Hermes 브랜치 PR 검사

- 모바일 전송 거절: 실행 중인 에이전트가 두 번째 메시지를 거절하면 모바일에서 미전송 사유를 현재 언어로 표시한다. 프로덕션 타입 검사와 테스트 타입 회귀 검사를 모두 통과해야 한다.
- 플러그인 RPC: 로컬 CLI 문맥에서 DevTools, 재시작, 로그 조회 요청을 실행한다. 각 테스트의 서비스 모의 객체가 호출되고 변경 코드 검사에서 금지된 타입 단언이 없어야 한다.
- 셸 실행 환경: zsh 실행 환경 시험 파일만 변경해도 PR 필수 셸 검사에 그 파일이 선택되고 실제 zsh 시험이 실행돼야 한다.
- CI의 컴퓨터 E2E 경로 필터가 추적 중인 PTY 소스를 가리키고, 데스크톱 영어 부팅 카탈로그와 모바일 번역 카탈로그가 각 검증기를 통과해야 한다.
- 데스크톱 E2E: 플로팅 창에서 탭을 추가해 선호 너비 330px와 좁은 창에서의 배치를 확인한다. 작업공간 이름에 이모지를 직접 입력하고 자동 이름 설정을 각각 켜고 끈 상태에서 표시 이름과 브랜치를 확인한다.
- WSL E2E: 기본 에이전트를 비운 시험 호스트에 연결한 뒤 메뉴에서 Claude 채팅을 한 번 연다. 응답, 배포판 중지 및 복구 과정에서 같은 세션이 유지돼야 한다.
- WSL 변환: 준비된 변환 저널로 데스크톱을 다시 열면 작업공간과 터미널 기록이 옮겨지고 해당 저널 파일이 제거된다.
- GitHub 작업 검색: 마지막 문자를 입력한 직후 또는 자동 검색 직후 Enter를 눌러도 최종 검색어의 건수·목록 요청이 각각 한 번이어야 한다.
- CLI에서 새 작업을 `worktree create --activate`로 열 때 에이전트를 생략하면 실행 호스트의 기본 에이전트와 Chat/CLI 선택을 따른다. Hermes·Chat 설정에서는 첫 에이전트 탭이 Hermes 채팅이며, 기본 에이전트가 비어 있거나 비활성화됐으면 일반 작업공간으로 열린다.
