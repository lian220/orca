# 외부 ACP 등록 개발 빌드

목표: 공식 앱을 보존한 별도 개발 앱에서 외부 ACP를 일반 에이전트 채팅으로 연결한다. 맥미니 Hermes·Jev·실행기·Chrome은 기존 외부 연결을 재사용한다. 공식 릴리스 포함 여부와 개발 검증은 구분한다.

구현 경계:

1. 사용자 지정 절대 경로의 등록 파일을 검증한다. 고유 agent ID, 절대 command, args 배열을 받는다. 내장 ACP 덮어쓰기와 중복은 거절한다. 등록은 앱 시작 시 로드한다.
2. 기존 AcpLaunchSpec·StructuredAgentRegistry·일반 ACP 전송/저장/재개를 재사용한다. 모델은 서버가 보고하며 클라이언트가 Jev 판단을 대신하지 않는다.
3. 일반 채팅 에이전트 조회와 화면에서 외부 ID를 전달한다. 기존 내장 에이전트의 터미널 실행 경로는 유지한다.
4. 개발 앱 전용 사용자 데이터 경로에서 실행한다. 공식 앱 DB를 복사하거나 덮어쓰지 않는다. 기존 원격 대화 재개 시험은 원격 세션이 idle인 것을 확인한 후 별도로 수행한다.

검증 순서: 등록 경계 실패 시험 → 구현 → ACP 기존 시험/타입 검사 → 개발 빌드 → 일반 채팅 실측 → 재시작/취소/보존 검증. 실제 시험 입력과 기대 결과는 ../test-cases/20261028-external-acp.md 참조.

공식 upstream 배포·PR 생성은 이 개발 검증과 별도다. 개발 빌드를 공식 앱으로 덮어쓰지 않는다.
